FP V2.3 — Source code

แตก ZIP แล้วเปิดโฟลเดอร์ FP ใน VS Code
เปิด Terminal แล้วรัน:
python3 -m http.server 8000 --directory dist
เปิด http://localhost:8000

โค้ดเว็บไซต์อยู่ใน dist/ ไม่ต้อง npm install หรือ build
ชุดทดสอบ: node tests.mjs (ต้องติดตั้ง Node.js)
README.md อธิบายฟังก์ชันและข้อจำกัด

เมื่ออัปขึ้น GitHub ให้อัปไฟล์และโฟลเดอร์ภายใน FP โดยคงโครงสร้างเดิม ไม่ใช่อัปไฟล์ ZIP เพียงไฟล์เดียว
หากนำไปโฮสต์แบบ Static Website ให้ใช้ dist เป็นโฟลเดอร์เผยแพร่
